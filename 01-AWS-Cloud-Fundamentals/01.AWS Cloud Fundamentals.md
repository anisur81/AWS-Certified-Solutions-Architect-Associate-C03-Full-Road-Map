# What is AWS?

AWS fundamentals refer to the core concepts, architecture, and primary services of Amazon Web Services (AWS), which is the world's leading cloud computing platform. 
Instead of buying and maintaining physical data centers and servers, AWS lets you rent IT resources on demand with a pay-as-you-go pricing model

AWS is a cloud computing platform that provides services such as computing power, storage, databases, networking, security, monitoring, and machine learning.
Instead of purchasing and maintaining physical servers, developers can use AWS resources when they need them and scale them according to their requirements.

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers on-demand IT resources such as servers, storage, databases, networking, security, and software services over the internet.

Instead of purchasing and maintaining physical servers, businesses can use AWS resources and pay according to their usage.

Key benefits:

- Scalability – Increase or decrease resources as needed.
- Flexibility – Choose from a wide range of cloud services.
- High Availability – Build applications across multiple Availability Zones.
- Security – Use AWS security services and controls.
- Cost Optimization – Pay for the resources you consume.
- Global Reach – Deploy applications around the world.

## 2. Cloud Computing Concepts

Cloud computing provides computing resources over the internet.

Three main cloud service models:

| Model | Description                                            | Example               |
| ----- | ------------------------------------------------------ | --------------------- |
| IaaS  | Provides virtual servers, storage, and networking.     | Amazon EC2            |
| PaaS  | Provides platforms to develop and deploy applications. | AWS Elastic Beanstalk |
| SaaS  | Provides ready-to-use software over the internet.      | Amazon QuickSight     |

Cloud deployment models:

- Public Cloud – Infrastructure shared across customers, with isolated resources.
- Private Cloud – Cloud infrastructure dedicated to one organization.
- Hybrid Cloud – Combination of on-premises infrastructure and cloud services.

## 3. AWS Global Infrastructure

AWS operates a global infrastructure to deliver reliable and scalable cloud services.

- Region: A separate geographical area where AWS operates its infrastructure.
- Availability Zone (AZ): An isolated location within a Region containing one or more data centers.
- Data Center: Physical facilities containing servers, networking, and storage equipment.
- Edge Location: A location used to deliver content with lower latency, commonly through Amazon CloudFront.

Example hierarchy:

```
AWS Global Infrastructure
        |
      Region
        |
  Availability Zones
        |
    Data Centers
```

## 5. AWS Identity and Access Management (IAM)

IAM controls who can access AWS resources and what actions they can perform.

Main IAM components:

- Users – Identities for individual users or applications.
- Groups – Collections of IAM users.
- Roles – Identities that provide temporary permissions.
- Policies – JSON documents defining permissions.
- MFA – Adds an additional authentication factor.

Best practices:

- Enable MFA for the root user.
- Avoid using the root user for daily tasks.
- Follow the principle of least privilege.
- Use IAM roles instead of long-term credentials where possible.
- Regularly review permissions.

## 6. AWS Shared Responsibility Model

AWS security is shared between AWS and its customers.

- AWS responsibility – Security OF the Cloud: Physical data centers, hardware, networking infrastructure, and underlying cloud infrastructure.
- Customer responsibility – Security IN the Cloud: Data, identities, access permissions, operating systems, applications, and network configurations, depending on the service.

For example, with EC2, customers manage the guest operating system and its patches. With RDS, AWS manages more of the underlying database infrastructure.

## 7. AWS High Availability and Scalability

- High Availability – Keeps applications available by reducing single points of failure.
- Fault Tolerance – Allows systems to continue operating when components fail.
- Scalability – Increases or decreases resources according to workload.
- Elasticity – Automatically adjusts resources based on demand.
- Load Balancing – Distributes incoming traffic across multiple targets.
- Auto Scaling – Automatically adjusts compute capacity.

Example: Deploy EC2 instances across multiple Availability Zones behind an Application Load Balancer.

## 8. AWS Pricing and Cost Management

AWS offers flexible pricing options:

- On-Demand – Pay for compute capacity without long-term commitments.
- Savings Plans – Reduce costs through a usage commitment.
- Reserved Instances – Discounted pricing for eligible services and configurations.
- Spot Instances – Use spare EC2 capacity at discounted prices, with interruption risk.

Cost management tools: AWS Cost Explorer, AWS Budgets, and AWS Pricing Calculator.
