# What is AWS?

AWS fundamentals refer to the core concepts, architecture, and primary services of Amazon Web Services (AWS), which is the world's leading cloud computing platform. 
Instead of buying and maintaining physical data centers and servers, AWS lets you rent IT resources on demand with a pay-as-you-go pricing model

AWS is a cloud computing platform that provides services such as computing power, storage, databases, networking, security, monitoring, and machine learning.
Instead of purchasing and maintaining physical servers, developers can use AWS resources when they need them and scale them according to their requirements.
